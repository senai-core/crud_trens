# CRUD de trens

Cadastro da frota e leitura de sensores simulados, com alerta quando um valor passa do limite.

- `trem.php`: cria e edita
- `simulador.php`: gera leituras
- `leituras.php`: lista e destaca o que passou de `limites.php`

Precisa do banco do `create_db.sql` rodando no XAMPP (`root`, sem senha).
